# Que Horas São Aí?

Aplicação web simples e acessível para conversão de horários
entre Brasil e Nova Zelândia.

## Objetivo

Facilitar a comunicação entre familiares que vivem em
diferentes fusos horários, especialmente usuários com
baixa familiaridade com tecnologia.

## Tecnologias

- HTML
- CSS
- JavaScript
